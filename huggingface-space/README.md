# Brain Bash AI

Static Hugging Face Space configuration for the Brain Bash AI game.

To create the Space, use **Static HTML** and copy the game files from the GitHub repository root into the Space repository. The app runs without server compute. The optional AI Game Master uses Transformers.js/WebGPU in the player's browser.
